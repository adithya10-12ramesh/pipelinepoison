# PipelinePoison

Research project studying prompt injection attacks against LLM-integrated DevOps pipelines.

## Structure
- `/payloads` — attack payload corpus (24-class taxonomy across 6 goals × 4 surfaces)
- `/harness` — Python modules for attack simulation and detection
- `/results` — experiment outputs, logs, evaluation data
- `/paper` — draft manuscript and figures
